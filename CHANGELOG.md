# CHANGELOG

## 1.1.0 - 2025-07-08

### Added
- Integración de un nuevo modelo de inteligencia artificial con soporte para **Bounding Box** para una mejor detección de incidencias.
- Desarrollo e implementación de una **página web pública** para visualizar y modificar el estado de las incidencias.
- Inclusión de etiquetas (`labels.txt`) compatibles con el nuevo modelo `.tflite`.

### Changed
- Mejora del frontend en la aplicación Android: ajustes en diseño, usabilidad y responsividad.
- Refinamiento del sistema de geolocalización y carga de imágenes.
- Optimización del rendimiento general de la app y refactorización del código Java para mayor legibilidad.

### Fixed
- Correcciones menores en estilos visuales y errores técnicos detectados durante pruebas.
