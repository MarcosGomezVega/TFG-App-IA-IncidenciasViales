# TFG-App-IA-IncidenciasViales

Este proyecto forma parte de mi Trabajo de Fin de Grado (TFG) y consiste en el desarrollo de una **aplicación móvil para la detección y reporte de incidencias viales utilizando inteligencia artificial (IA)**. El sistema permite que los usuarios tomen fotografías de desperfectos (como baches, grietas, señales horizontales deterioradas, etc.), los clasifiquen automáticamente mediante un modelo entrenado con visión por computador y los reporten junto a su ubicación geográfica.

Además, el proyecto se completa con una **plataforma web de administración** para visualizar y gestionar las incidencias reportadas, y con funciones en la nube mediante **Firebase**, que permiten el envío de notificaciones en tiempo real a los usuarios involucrados.

## Tecnologías utilizadas

- Android (Java)
- TensorFlow Lite (modelo IA de tipo Bounding Box)
- Firebase (Cloud Functions, Firestore, Authentication)
- Web (HTML, CSS, JavaScript)
- Git / GitHub

## Funcionalidades principales

- Detección automática de incidencias en imágenes mediante IA.
- Geolocalización del problema detectado mediante el GPS del dispositivo.
- Envío del reporte a una base de datos en la nube.
- Página web para administración, seguimiento y actualización de incidencias.
- Notificaciones automáticas cuando se actualiza una incidencia.
